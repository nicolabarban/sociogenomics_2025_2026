# Data access

This folder contains small datasets that are safe to keep in the GitHub repository.

Large datasets (e.g., full PLINK datasets, summary statistics, and VCFs) are hosted on Dropbox.
Use the download helper:

```
bash scripts/download_data.sh <DROPBOX_URL> [output_file]
```
